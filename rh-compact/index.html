What this is. The compact edition of the shorter Lean 4 proof of the Riemann Hypothesis and GRH, published by Anthropic and Claude in November 2026 and based on Levent Alpöge's proof, joined into a single plain-text stream: .

Order. Each file comes after the files it imports, so nothing is used before it appears. A one-line header marks where each file begins; the Lean text itself is unchanged.

Getting around. Scroll normally, drag the bar on the right to travel the whole text, or jump by line number, percentage or file name. The address bar tracks your line, so any position can be linked.
